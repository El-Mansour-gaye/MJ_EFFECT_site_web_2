MISSION : ADAPTATION FRONT-END - SITE E-COMMERCE PARFUMERIE DE LUXE

1. CONTEXTE ET OBJECTIF GÉNÉRAL
Transformer le prototype actuel (Next.js/Tailwind) en une boutique en ligne professionnelle pour une nouvelle marque de parfums. Le design doit communiquer le luxe, la simplicité et l'élégance. Vous avez accès à un repo contenant une copie du projet actuel : vous êtes libre d'adapter ce projet directement ou de repartir sur un nouveau front-end à part en vous en inspirant.

2. INSPIRATION ET DESIGN
- Direction artistique : Épure, minimalisme, typographies soignées.
- Référence : Allez voir les sites de grandes maisons de parfumerie pour vous inspirer du niveau de détail (espacements, animations fluides, présentation des flacons).
- Vous avez une totale liberté sur les éléments de design pour atteindre ce rendu "haut de gamme".

3. GESTION DES DONNÉES ET IMAGES (DÉVELOPPEMENT)
- Données Produits : Toutes les informations et photos des produits vous seront fournies.
- Workflow : Pour le développement, utilisez des données statiques (fichiers JSON ou mock data).
- Images : Stockez les images fournies dans le dossier `/public` du projet.
- Dynamisation : La connexion à Supabase pour rendre ces données dynamiques sera effectuée par nos soins après votre travail.

4. TÂCHES FRONT-END
- Adaptation de la vitrine (Storefront) : Accueil, pages collections, fiches produits, panier, checkout.
- Adaptation de l'interface Admin : Moderniser l'interface de gestion du catalogue pour qu'elle soit aussi élégante que la partie publique.
- Responsive Design : Le rendu doit être parfait sur mobile, tablette et desktop.

5. TRAITEMENT DES ASSETS (LOGOS ET IMAGES)
- Logos : Suppression du fond (détourage) pour une intégration parfaite.
- Images Produits : Normalisation si nécessaire (ex: même ratio pour tous les flacons) et réduction de la taille des fichiers pour optimiser les performances (format WebP recommandé).

6. LIVRABLES
- Une version du projet visuellement aboutie, fluide et utilisant les assets réels du client de manière statique.

L'objectif est d'avoir un site visuellement fini, prêt pour l'intégration finale des données dynamiques.
