# Plan de Structuration de Base de Données : TSM

Ce document adapte la structure de données de l'ancien site (MG Effect) aux réalités spécifiques de **TSM**, en se basant sur votre catalogue actuel.

---

## 1. Adaptation des Colonnes (Mapping)

Voici comment organiser les informations de TSM dans les colonnes existantes de la table `produits` :

| Colonne | Utilisation pour TSM | Exemple |
| :--- | :--- | :--- |
| **nom** | Marque + Numéro + Nom/Couleur | `TSM - # 92 # - Diamant Vert` |
| **prix_fcfa** | Prix fixe par gamme | `8000` ou `14000` |
| **category** | Gamme de produit | `Body Spray` ou `Parfum de Niche` |
| **subcategory**| Genre / Cible | `Femme` ou `Homme` |
| **intensite** | Accords principaux | `Fruité ; Caramel ; Vanille ; Boisé` |
| **famille_olfactive** | Notes Olfactives (Tête, Cœur, Fond) | `Tête: Poire... / Cœur: Rose... / Fond: Praliné...` |
| **details** | Contenance / Format | `30ml – 1.69FLOZ` ou `250ml` |
| **slug** | Identifiant URL unique | `tsm-niche-femme-92` |

---

## 2. Stratégie de Catégorisation

Contrairement à MG Effect qui vendait des marques variées, TSM se concentre sur sa propre ligne numérotée. Je recommande de structurer vos catégories ainsi dans l'admin :

- **Catégories principales :**
    - `Body Spray`
    - `Parfum de Niche`
- **Sous-catégories :**
    - `Femme`
    - `Homme`
    - `Unisexe` (si applicable)

---

## 4. Conseils Spécifiques pour TSM

1.  **Uniformité des Noms :** Utilisez toujours le même format (ex: `TSM - # NUMERO #`) pour que la recherche sur le site soit efficace quand un client tape juste un chiffre.
2.  **Gestion des "Accords" :** Dans l'interface client, la colonne `intensite` (renommée "Accords" dans le code si besoin) est cruciale pour les parfums de niche.
3.  **Images :** Comme vos produits sont numérotés, nommez vos fichiers images de façon organisée dans le bucket Supabase : `niche-femme-92.jpg`, `spray-vert-92.jpg`, etc.
4.  **Champs vides :** Pour les Body Sprays, vous n'avez pas forcément le détail Tête/Cœur/Fond. Vous pouvez simplement mettre la couleur ou une description courte dans `famille_olfactive`.

---

## 5. Modifications Code recommandées

Dans le fichier `lib/types.ts` ou dans vos composants d'affichage, vous pourriez vouloir changer les labels :
- Changer "Intensité" par "**Accords Principaux**"
- Changer "Famille Olfactive" par "**Notes Olfactives**"
